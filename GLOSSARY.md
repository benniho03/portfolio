# Portfolio

Benni Holderles persönliche Portfolio-Website auf holderle.de: ein Schaufenster für seine Projekte, später ggf. auch zur Akquise von Freelance-Kunden.

## Language

**Startseite**:
Die einzige inhaltliche Seite der Website; sie stellt Benni vor und stellt alle Projekte aus.
_Avoid_: One-Pager, Landingpage, Übersichtsseite, Home

**Projekt**:
Eine Arbeit von Benni (Anwendung, Spiel, Website oder Design), die auf der Startseite ausgestellt wird. Ein Projekt hat keine eigene Unterseite.
_Avoid_: Arbeit, Work, Referenz, Case Study

**Technologie**:
Ein Werkzeug, eine Sprache oder ein Framework mit Name und Logo, das in Projekten verwendet wurde (z. B. Next.js, Laravel, Figma).
_Avoid_: Tag, Tech, Stack-Item

**Skill**:
Eine Technologie, die Benni als eigene Kompetenz auf der Startseite hervorhebt – unabhängig davon, ob ein ausgestelltes Projekt sie verwendet.
_Avoid_: Kompetenz, Fähigkeit, Tech-Stack

**Gewichtung**:
Wie stark Benni einen Skill hervorheben will, auf einer Stufe von 1 (wenig) bis 3 (stark). Sie sagt nichts darüber aus, wie gut er die Technologie beherrscht.
_Avoid_: Level, Kenntnisstand, Erfahrung, Priorität

**Rechtliche Seite**:
Das Impressum oder die Datenschutzerklärung. Eine eigene Seite neben der Startseite, die nur rechtliche Pflichtangaben enthält und keine Inhalte zeigt.
_Avoid_: Legal Page, Unterseite

## Werdegang

**Werdegang**:
Die chronologische Zeitleiste von Bennis beruflichen und schulischen Stationen.
_Avoid_: Lebenslauf, CV, Berufserfahrung, Timeline

**Station**:
Ein einzelner Abschnitt im Werdegang – eine Anstellung oder eine Ausbildung bzw. ein Studium – mit Zeitraum, Organisation und den dort verwendeten Technologien.
_Avoid_: Eintrag, Position, Job, Erfahrung
